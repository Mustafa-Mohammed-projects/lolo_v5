# AboLolo – لعبة قتال تكتيكي (Kotlin / Android)

## البناء عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات هذا المجلد (بما فيه `.github` و `gradle`).
2. افتح تبويب **Actions** ← **Build AboLolo APK** ← يبدأ تلقائياً عند أي push (أو اضغط Run workflow).
3. بعد النجاح نزّل `AboLolo-apk` من أسفل صفحة التشغيل (Artifacts) وفيه `AboLolo.apk`.
4. لإصدار على صفحة Releases: `git tag v1.0 && git push --tags`.

## استبدال الملفات بملفاتك
- شاشة البداية: `app/src/main/res/drawable-nodpi/presplash.png` (تظهر 3 ثوانٍ على خلفية سوداء).
- أغنية النهاية: `app/src/main/res/raw/endgamelolo.ogg` — إن كانت أغنيتك mp3 فاحذف ملف ogg وضع `endgamelolo.mp3` (لا يجوز وجود الاثنين معاً).

## ما الجديد (النسخة ثلاثية الأبعاد - المرحلة 1)
- عالم ثلاثي الأبعاد حقيقي (OpenGL ES 2.0) بكاميرا خلف الكتف مائلة، مجسّمات منخفضة التفاصيل للجنود والعربات والطائرات والمباني.
- تحكم على طريقة فري فاير: عصا حركة يسار، السحب باليمين لتدوير الكاميرا والتنشين، زر نار، تصويب مساعد خفيف.
- 9 أسلحة واقعية: مسدس، AK-47، G3، ماغنوم، آر بي جي، رشاش خفيف SMG، شوزن، قناص بمنظار، رشاش PKM — ذخيرة احتياطية، إعادة تعبئة، ارتداد وانتشار للرصاص.
- عربات بفيزياء قيادة (تسارع وانعطاف وقصور) وبرج مدفع 23 ملم مستقل التدوير.
- صورتا القبة والسافنا من صورتك تظهران في القوائم والحوارات.
- المرحلة 2 (قادمة): جبن الدينار، توقيع معاهدة السلام مع الجنجا والاحتفال، وصقل المعارك 3-5.
